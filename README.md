# «Большая мама» — сайт мороженого

Одностраничный сайт-концепция. HTML, CSS и JavaScript разделены на отдельные файлы.

## Структура проекта

```
index.html      — разметка страницы
styles.css      — все стили и адаптивность
script.js       — меню, модальное окно заказа, валидация и отправка форм
images/         — локальные изображения (используются на сайте)
```

Изображения `Gemini_Generated_Image_*.jpg` — исходники. На сайте используются
оптимизированные копии:

- `images/ice-cream-vanilla.jpg` — ванильный рожок;
- `images/ice-cream-chocolate.jpg` — шоколадное мороженое;
- `images/ice-cream-strawberry.jpg` — клубничное мороженое;
- `images/ice-cream-waffle.jpg` — вафли с мороженым.

## Отправка форм

Формы заказа и обратной связи больше не показывают ложное «успешно отправлено».
По умолчанию они открывают почтовый клиент с уже заполненным письмом
(`CONTACT_EMAIL` в `script.js`). Сообщение об успехе появляется только после
передачи данных в почтовый клиент или после успешного ответа сервера.

Чтобы отправлять заявки автоматически:

1. Зарегистрируйтесь на Formspree, FormSubmit или аналогичном сервисе.
2. Получите URL обработчика.
3. Укажите его в `script.js`:

```js
var FORM_ENDPOINT = 'https://formspree.io/f/xxxxxxxx';
```

Если `FORM_ENDPOINT` пуст, используется запасной вариант через `mailto:`.
При ошибке запроса пользователю показывается сообщение с прямой ссылкой
на почту и телефон.
